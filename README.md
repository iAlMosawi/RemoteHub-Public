# RemoteHub

RemoteHub is an upcoming secure remote-access application for Apple devices.

## Planned capabilities

Remote desktop, Mac audio, keyboard and pointer control, clipboard synchronization, SSH/SFTP, file transfer, multiple displays, window streaming, Picture in Picture, Wake-on-LAN, encrypted direct connections and relay fallback.

## Platforms

- iPhone / iPad
- macOS host
- Additional server-management integrations are planned.

## Security

RemoteHub is being designed around authenticated devices, explicit pairing and end-to-end encrypted remote sessions.

## Repository policy

This public repository contains product documentation and public project information only. The application and backend source code are maintained separately in a private repository.

## Status

Early development. APIs and features may change before release.
